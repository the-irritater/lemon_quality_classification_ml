# Lemon Quality Classification using Machine Learning

This project classifies lemons into four quality categories:
Excellent, Good, Processed Products, and Disqualified using
Haralick texture features and machine learning classifiers.

## Dataset
Hiroshima Lemon Dataset

## Techniques
- Grayscale conversion
- Haralick texture feature extraction
- StandardScaler
- Logistic Regression, SVM, KNN, Random Forest, Neural Network, etc.

## Results
Logistic Regression achieved highest validation accuracy.
